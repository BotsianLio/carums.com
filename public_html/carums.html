Advanced Search Advice

Carum Name sometimes could be elusive. Use our advanced search system with CarumTag could save your time to enter a carum or look for a topic. Here we have provided an example and some explanations for you.

Eg: The CarumTag of Audi R8 (Type 4S) Carum is

#AUDR8XT4S

#:    Use a hashtag to start an advanced search.
AUD: Each brand in our system has an abbreviation, here 'Audi' is 'AUD'.
R8X: Each model has an abbreviation too, if a model name has fewer than 3 letters, use 'X' to fill the blank, here 'R8' is 'R8X'.
T4S: Some car models have to be distinguished by using model codes, if a model code has fewer than 3 letters, use 'X' to fill the blank, here 'Type 4S' is 'T4S'.

If you want to search a specific topic in a carum, just type keywords after CarumTag.
Can't remember model or model code? No worries, our search system will list all choices under the search bar after you have input the abbreviation of a brand.
